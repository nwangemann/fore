# 4. Golf theme

- Status: accepted
- Date: 2026-11-25

## Decision

The name is a pun on forecast, so the design leans into golf: mowing stripes, scorecard paper, a 7-day scorecard scored against par, "the front nine" for hourly, "plays like" for feels-like, and "FORE!" for official alerts (the real warning shout). Shrikhand for display type, Space Grotesk for body, both from Google Fonts under the OFL. Weather icons are emoji to avoid an icon dependency.
